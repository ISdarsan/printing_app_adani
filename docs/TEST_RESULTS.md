## Re-run it yourself

```powershell
flutter analyze; flutter test
node --test tool/rules_diff.test.mjs tool/verify_deploy_files.test.mjs
node tool/check_indexes.mjs
python tool/validate_workbook.py
```

Emulator (fake project; create a temporary `firebase.test.json`, then delete it):
```powershell
'{"firestore":{"rules":"firestore.rules"},"emulators":{"firestore":{"port":18080},"ui":{"enabled":false}}}' | Set-Content firebase.test.json
firebase emulators:exec --only firestore --config firebase.test.json --project demo-canteen-test "cd security-tests && node --test"
Remove-Item firebase.test.json
```
Pick a new port if one is "taken" (a previous emulator may still be closing). For the candidate: set `$env:RULES_FILE='proposals/firestore.rules.candidate'` first and pass the older test files.
